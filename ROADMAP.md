# FinanceOS — закреплённый план развития

Согласован 9 ноября 2026. Текущая облачная версия: **v0.18.18** (27 ноября 2026: Ночной атлас, ожидаемые суммы и управление планами/категориями). Следующие версии — план, а не выполненные функции. Закрепление плана не является командой начать разработку или загрузку. Менять порядок и объём — по согласованию с владельцем проекта. Номера будущих версий можно сдвигать при дополнительных выпусках без повторного согласования, сохраняя порядок задач (подтверждено владельцем 13.11.2026).

## Общие требования

- Одна беседа — один общий бюджет; участник существующей беседы не получает отдельную копию данных.
- Новый бюджет получает отдельное облачное пространство. Google Sheets в рабочую схему не возвращаем.
- Незнакомые профили пока не регистрируются автоматически; текущий доступ ограничен. Регистрация, подписки, платежи и экспорт пока не реализованы.
- Стандартный набор предлагается с подтверждением, настройка общая для бюджета.
- Автотесты обязательны для каждой новой функции: расчёты, кнопки/ввод, совместная работа, хранение/восстановление, безопасность, таймауты и повторы.
- Для воспроизводимого бага добавлять тест, который обнаруживает ошибку и проходит после исправления.
- Порядок выпуска: изменения → автотесты → отдельный тестовый бюджет → облако → безопасная проверка.
- Рабочие финансы автотесты не изменяют. Покрытие критичных сценариев важнее формального процента.
- Критические исправления выпускаются немедленно; между крупными версиями допускаются дополнительные выпуски .2, .3 и далее.
- Изменения и архивы подписывать номером версии, хранить в известной папке проекта.

## Решения, которые ещё нужно принять

Цена, длительность пробного периода, статус для приёма оплаты, платёжный сервис, правила возвратов, доступность экспорта после окончания ранее оплаченной подписки. Автосписания не включать по умолчанию.

## Правило нумерации · закреплено 13.11.2026

Ближайший порядок: детализация диаграмм → оформление/навигация и проверка расчётов → тестовая инфраструктура → интерфейс новичка → обратная связь → регистрация бюджетов → подписки → экспорт → платежи → отложенные каналы.
Если между задачами появляется дополнительный выпуск, сдвигать номера следующих запланированных версий и обновлять этот документ. Выпущенные версии не перенумеровывать. Сдвиг номера не означает изменения порядка, объёма или выполнения задач. Новое согласование для самого сдвига не требуется. Закрепление плана само по себе не запускает разработку.
