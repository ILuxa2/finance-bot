# v0.18.18 · Ночной атлас и управление бюджетом

Статус: реализация подготовлена локально; публикация и результаты проверок фиксируются после завершения. Согласованный объём — раздел ближайшего выпуска в ROADMAP.md.

## Поведение

- Отчёт сохраняет прежний текст и получает карточку с балансом, свободными деньгами и остатком плана. Тёмные изображения используют глубокий синий фон с переливом справа сверху. Светлая тема остаётся доступной. Состав категорий разделов, суммы и проценты сохранены; пакет изображений доставляется одним сообщением.
- Настройки → Оформление: фон чата, образец фона сообщений, инструкция и выбор темы диаграмм. Изображение фона входит в пакет приложения. Фон и цвет пузырьков устанавливаются вручную в клиенте VK; бот не может применить их автоматически. Нативные кнопки используют стандартные роли primary/secondary/positive/negative; точные оттенки и градиенты макета не обещаются.
- Ожидаемые операции: выбор → предпросмотр → необязательная правка суммы → подтверждение. Правится только конкретное поступление или списание; сумма регулярного правила сохраняется. Предпросмотр переживает перезапуск. Повторное подтверждение не создаёт вторую запись; подтверждение отменяется общим undo.
- Удаление плана: месяц → раздел → категория либо весь план раздела → подтверждение. Учитываются импортированные и добавленные планы. Планы других месяцев, категории и история сохраняются. Кредитные строки управляются карточками долгов. Удаление помечается отдельной сохраняемой правкой; весь набор удалений отменяется одним undo. При повторном добавлении прежняя сумма не возвращается поверх новой.
- Разделы: создание и переименование, выбор получателя категорий перед удалением заполненного раздела. Системное «Прочее» сохраняется как место нераспределённых категорий.
- Категории: операции категории, переименование, перенос, явное объединение и удаление с выбором получателя данных. Объединение создаёт канонический псевдоним, сохраняя ID, суммы, даты и комментарии операций; планы складываются по месяцам. Источники дохода и расходные категории не объединяются между собой; кредитные категории защищены. Удаление пустой категории убирает её из выбора; архив остаётся доступен для восстановления.
- При создании раздела или категории предлагаются похожие существующие названия. Точное совпадение нельзя создать повторно. Выбор предложения не меняет бюджет; отдельное создание требует подтверждения.
- История: убрана дублирующая кнопка «Повторить», открывавшая редактор. Редактирование из истории возвращает в исходную историю с периодом, категорией и страницей; самостоятельный список редактора сохраняет собственную страницу. Возврат из категории отчёта снимает уровень истории со стека.

## Хранение и совместная работа

Новые черновики используют существующий сохраняемый контекст пользователя; поля финансового состояния не перезаписываются при публикации. Для удаления плана в PlanEdit добавлен необязательный deleted; старые записи читаются как deleted=false. Черновики подтверждения проверяют актуальность данных. Undo включает планы, разделы, псевдонимы и регулярные решения. Пользовательские финансы не используются автотестами.

В текущем формате категории имеют уникальное имя во всём бюджете. Поэтому две независимые одноимённые категории разных разделов не создаются: выбирается существующая категория. Явное объединение доступно для разных существующих названий. Новый формат с отдельными ID категорий в этот выпуск не входит.

## Проверки

Release18Test проверяет удаление исходных планов и всего раздела, перезапуск, отмену, повторное добавление без восстановления старой суммы, правку ожидаемой суммы без изменения правила, повторное подтверждение, перенос раздела, объединение истории/планов, подсказки названий и доступность изображений.

Существующие регрессионные наборы проверяют расчёты, историю, ввод, чеки, совместную работу, хранение и доставку. Проверки публикации контролируют сохранение конфигурации и запрет небезопасных повторов загрузки.
