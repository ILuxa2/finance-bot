- [x] После сохранения сохранена доступность отмены изменения; для дохода/расхода/чека кнопка повторного ввода.
- [x] Расходы одной картинкой с разделами и всеми категориями, включая категории на нескольких прежних страницах. Полоса = доля своего раздела, не максимум всех категорий.
- [x] Более тёмная общая тема; светлый вариант. Настройка сохраняется прежним механизмом.
- [x] Отчёт с диаграммами: сгруппированные расходы, доходы при наличии, сравнение доходов/расходов; прежний текст отчёта.
- [x] Одно сообщение для изображений: старые большие очереди тоже объединяются в составные изображения до лимита 10 вложений; прежних сообщений «продолжение» нет.
- [x] Диаграмма доходов не отбрасывает категории после первых 12.

- [x] Перенос отдельной операции в категорию: раздел/прямой ввод, предварительный просмотр, сохранение черновика и подтверждения после перезапуска, отмена, защита повторного подтверждения, неизменность баланса и связанных долгов/целей.

## Проверки

Автотесты используют искусственные данные и локальные HTTP-заглушки. Новые проверки `OperationCategoryMoveTest` (перенос и финансовые инварианты) и `InterfaceAgreementTest` зарегистрирована в `build.ps1`: состав меню, положение навигации, помощь/команды, отдельные настройки, численная и пиксельная проверка 50%-й полосы, обе темы, чтение отчётов без изменения финансов.
Обновлены прежние проверки только там, где согласованно изменился контракт: подписи кнопок, глубина настроек, размер страницы, цвет фона, состав диаграмм и одно сообщение вместо продолжений.

Проверены все 64 зарегистрированных Java-набора по группам, а также 2 Python-проверки публикации. После последней правки отмены повторно прошли затронутые сценарии ввода/разделов/переноса и все 12 облачных наборов. При одном параллельном прогоне Windows временно отказала в атомарной замене файла внутри sandbox Temp; повторный последовательный облачный прогон прошёл без изменения логики записи. Реальное облако не вызывалось. Для воспроизведения: `./build.ps1`, либо `./test.ps1 -NoBuild` после сборки. Python: `python -m unittest discover -s scripts -p 'test_*.py'`.
