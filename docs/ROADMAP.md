## Будущие версии

- **Docker:** воспроизводимый образ, healthcheck и Docker Compose.
- **GitHub Actions:** lint, compile, tests и сборка образа для pull request.
- **Автотесты:** unit-тесты расчётов, mock Google Sheets и интеграционные Telegram-сценарии.
- **Web dashboard:** графики, фильтры и управление данными вне Telegram.
- **OCR чеков:** распознавание суммы, даты и позиций с подтверждением пользователя.
- **AI financial advisor:** объяснимые рекомендации на основе агрегатов с явными ограничениями безопасности.

Порядок будущих релизов определяется после стабилизации автоматических тестов; обещанных дат нет.
