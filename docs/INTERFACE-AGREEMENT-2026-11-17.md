# Согласованный интерфейс FinanceOS

Дата согласования: 17.11.2026. Статус: утверждённая спецификация для реализации и проверки, НЕ описание уже внедрённой версии. Номер релиза назначается при реализации. Текущие исторические документы сохраняются; при изменении интерфейса приоритет у этого согласования. Новые изменения кнопок и сценариев согласовываются с пользователем.

## 1. Главное меню

После `/start` показываем кнопки, а не список команд:

| Левая кнопка | Правая кнопка |
| --- | --- |
| 💸 Расход | 💰 Доход |
| 🧾 Чек | 📊 Отчёт |
| 📜 Все операции | 📋 Планы |
| ⏳ Ожидают | ⚙️ Ещё |
| ❓ Помощь | |

Ещё: 💳 Долги; 🎯 Цели; 📈 Прогноз (вместе с долговой свободой); 📜 История (тот же просмотр операций); 📊 Диаграммы; 🔁 Регулярные платежи; ⚙️ Настройки; ⬅️ Назад.
Основное управление кнопками. Команды остаются альтернативой и доступны через помощь.

## 2. Расход и доход

Раздел → категория → сумма и комментарий → сохранение. Выбор кнопками или текстом; на шаге раздела разрешён прямой ввод категории. Точное совпадение без учёта регистра и лишних пробелов используется сразу. Для похожих названий предложить существующее либо создание введённого; не объединять молча. При одинаковых названиях уточнить раздел. Применять также при создании и переименовании.

Подсказка: «Выберите кнопкой или напишите название категории». Сумма и комментарий одним сообщением: `500.50, продукты`; для дробных сумм точка.

Разделы: существующие, новый раздел, назад, отмена, меню. Категории: существующие, новая категория, назад, отмена, меню. Пагинация строго «⬅️ Предыдущие» / «➡️ Следующие». Новые сущности сохраняются только вместе с окончательной операцией.

Для новой категории расхода: «Не планировать»; «В существующий план»; увеличение плана раздела на сумму расхода; другая сумма увеличения. Для дохода вопрос о плане расходов не задаётся.

После записи: сумма, раздел, категория, комментарий, фактический баланс; «Ещё расход/доход», «Отменить изменение», «Меню».

## 3. Чек

Фото/текст → проверка суммы, даты и магазина/комментария → одна категория либо разбивка. Неизвестная сумма не считается нулём. Проверка: всё верно, изменить сумму/дату/комментарий, другой чек, отмена.

В разбивке видны итог, распределено, остаток. Добавить/изменить/удалить часть; весь остаток в выбранную категорию. Нельзя превысить остаток, завершение после полного распределения. Затем итоговая проверка и сохранение. До этого финансовых изменений нет. Отмена сохранённого чека отменяет все части одним действием; возможный дубликат требует предупреждения. После сохранения: ещё чек, отменить изменение, меню.

## 4. Отчёт

Первый экран: с диаграммами; без диаграмм; за дату; за период; меню. Без кнопки «Назад» на первом экране. В выборе даты/периода назад возвращает к вариантам отчёта.

Сохранить достаточный прежний текст отчёта. Отчёт и ВСЕ приложенные диаграммы одним сообщением, без перелистывания/продолжений; при необходимости объединять изображения. Под результатом: по разделам; по категориям; за дату; за период; сравнить месяцы; меню.

Раздел → категории → операции. По категориям открывает категории напрямую. Текстовое название сразу открывает операции категории за период отчёта; похожие варианты уточняются, одинаковые названия требуют выбора раздела, отсутствие совпадений оставляет выбор открытым. Здесь новые категории не создаются.

Сравнение двух месяцев: доходы, расходы, разница в рублях и процентах; снижение расходов зелёным, увеличение красным, без изменений нейтрально.
Свободные деньги = фактический баланс − оставшиеся плановые расходы. Незапланированные расходы отдельно; уже потраченные суммы повторно из баланса не вычитать.

## 5. Диаграммы

Период: текущий/предыдущий месяц, выбрать месяц, за период, назад, меню. Виды: расходы; доходы; доходы и расходы; план/факт. Под результатом: изменить период, другой вид, назад, меню.

Расходы — одна картинка, разделы и все категории горизонтальными полосами. У раздела итог и доля всех расходов. У категории сумма и доля своего раздела. Полная полоса = 100% расходов СВОЕГО раздела; длина обязана совпадать с процентом. Общую шкалу максимальной категории из макета НЕ использовать.

Доходы — состав по категориям. Доходы/расходы — сравнение по дням или месяцам в зависимости от периода. План/факт — сравнение по разделам, отдельно от обычного отчёта.
В отчёт с диаграммами входят расходы, доходы и их сравнение, вместе с текстом одним сообщением.
Тема единая для всех диаграмм: светлая/тёмная; согласован более тёмный, близкий к чёрному фон. Макеты показывают стиль, но в них ещё старая шкала: при реализации применять правило процентов выше.

## 6. Все операции и карточка

По 10 записей на странице, сначала новые, во всех списках операций. Тип, дата, сумма, категория, сокращённый комментарий; полный комментарий в карточке. Выбор операции компактными кнопками с датой и суммой по две в ряд. Пагинация обновляет текущее сообщение. Возврат из карточки сохраняет страницу и фильтры.

Фильтры: текущий/предыдущий/выбранный месяц, период, всё время; тип (все, расходы, доходы, долги, цели, переводы); раздел/категория с вводом названия; сброс. В списке категории можно написать другую категорию и переключиться.

Карточка: дата, сумма, раздел, категория, комментарий. Кнопки: дата; сумма; «📂 Перенести в категорию»; комментарий; удалить; назад; меню. Перенос: выбор кнопками/текстом, старый и новый путь, подтверждение. Сохраняет сумму/дату/комментарий, баланс не меняет. Статистика пересчитывается.
Редактируются ВСЕ типы; для долгов/целей пересчитываются остатки. Удаление с подтверждением. После записи доступна отмена, восстанавливающая связанные суммы.

## 7. Планы

Кнопки: план/факт; изменить план; копировать планы; меню.
План/факт: текущий, предыдущий, выбрать месяц. Все категории внутри визуально отделённых разделов, план, факт, остаток, прогноз конца месяца.
Изменение: текущий/следующий/выбранный месяц → раздел → категория. Изменить сумму, добавить/убрать из плана; категория и операции при удалении плана сохраняются. Текущие и будущие планы редактируются.
Копирование: источник → назначение → просмотр → изменение названий/категорий и сумм → подтверждение. При существующих планах объединить/заменить, с предварительным результатом.
Баланс конца месяца = текущий баланс + ожидаемые регулярные доходы − оставшиеся плановые расходы. Прошлый неизрасходованный план не резервирует деньги нового месяца; фиктивный доход не создавать.

## 8. Ожидают и напоминания

Наступившие неподтверждённые регулярные поступления/платежи. Карточка: подтвердить; изменить сумму; изменить дату; пропустить; назад; меню. Изменения только для события, не правила. Подтверждение создаёт операцию; пропуск после подтверждения не двигает деньги. При отсутствии записей сообщение об отсутствии ожидающих и меню.

Напоминания: за день, в день, ежедневно при просрочке; одно на общую беседу. Время/часовой пояс и включение в настройках. Деньги не списываются автоматически. Кнопки уведомления: подтвердить, напомнить позже, открыть. Отложить на час, 3 часа, завтра, выбранные дату/время, отключить для этого события. Дата платежа и правило не меняются. Подтверждение/пропуск прекращает напоминания.

## 9. Регулярные платежи

В «Ещё»: регулярный доход; регулярный расход; мои правила; ожидают; назад; меню. Создание: название → раздел/категория → сумма → день месяца → начало/окончание или бессрочно → напоминания → проверка → сохранить.
Несуществующий день месяца заменяется последним. Изменение, пауза, возобновление, удаление действуют на будущие события, не на записанные операции. Кредитные платежи из карточек долгов, без дублирования регулярным расходом. Движение денег после подтверждения.

## 10. Долги

Мои долги, добавить, внести платёж, назад, меню. «Я должен» / «Мне должны». Название, остаток, ежемесячный платёж, ближайшая дата либо без расписания.
Карточка: остаток, ближайший и последний платёж. Действия: платёж, график, изменить, закрыть, назад. Создание не двигает деньги. График включается отдельными кредитными строками в план/факт и ожидающие, не дублируется. Последний платёж не больше остатка. Выплата долга уменьшает баланс/остаток; возврат пользователю увеличивает баланс и уменьшает долг. Закрытие: окончательный расчёт либо без движения денег, с подтверждением.

## 11. Цели

Мои цели, создать, назад, меню. Название, сумма, срок/без срока. Карточка: накоплено, цель, прогресс, остаток, срок. Пополнить; вернуть деньги; операции цели; изменить; завершить; удалить; назад; меню.
Пополнение уменьшает доступный баланс, возврат увеличивает. Накопления меняются операциями. Показывать отдельно от расходов на покупки. Завершение/удаление: вернуть средства либо записать расходом, итог и подтверждение. Отмена восстанавливает обе суммы.

## 12. Прогноз

1/3/6/12 месяцев. Баланс, ожидаемые доходы, плановые расходы, в том числе долги, итог, остаток долгов и дата последнего платежа. Кредит только до погашения, последний платёж ограничен остатком; не считать долг дважды в плане и графике. Нет будущих планов — предупреждение о возможном завышении.
Кнопки: по месяцам, график долгов, диаграмма, назад, меню. Первый назад → Ещё, из деталей → прогноз с сохранённым горизонтом. Просмотр не меняет финансы.

## 13. Настройки

Разделы и категории; лимиты (сохранить существующую функцию); тема диаграмм; напоминания; очистка чата; назад; меню.
Создание/переименование/перенос/удаление категорий и разделов с сохранением истории; при использовании сначала предложить перенос данных. Очистка сейчас с подтверждением, автоочистка по сроку (например старше суток), сообщения бота и пользователя в пределах прав VK. Финансовые данные не удалять; ограничения показывать явно. В общей беседе настройки учёта общие.

## 14. Помощь

Краткое назначение кнопок, ввод названием, пример `500.50, продукты`, дроби через точку. Кнопки: список команд, обратная связь, меню. Команды доступны, но не показываются по умолчанию.
Обратная связь: ошибка/предложение/вопрос → текст → подтверждение отправки → номер обращения. Финансовые данные/секреты автоматически не прикладывать.

## 15. Общие правила и критерии проверки

- Единое расположение навигации: «⬅️ Назад» всегда в нижнем ряду слева на экранах, где предусмотрена. «🏠 Меню» — в том же ряду справа, если предусмотрена. Если «Меню» нет, «Назад» остаётся слева. Отмена и пагинация располагаются выше, чтобы позиция «Назад» не менялась. На экранах без возврата кнопку не добавлять.

- Каждое действие сопровождается загрузкой, заменяемой результатом либо убираемой после него.
- Ошибка понятная, без вечного ожидания; повторить/назад/меню. Повтор не дублирует операцию.
- Успех только после успешной записи.
- Назад сохраняет черновик. Отмена полностью очищает и возвращает меню без финансовых изменений. Меню при несохранённых данных спрашивает сброс.
- Устаревшие кнопки объясняются и ведут к актуальному экрану.
- В беседе общий бюджет, независимые черновики участников.
- Формат «Название · 1 000 ₽», текст и числа разделяются точкой в обе стороны. Цветовые отметки сопровождаются объяснением.
- Проверять расчёты, ошибки/повторы/параллельных участников/отмену/границы страниц и дат на искусственных данных. Не использовать реальные финансы для тестовых записей.
